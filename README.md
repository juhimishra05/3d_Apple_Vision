# 3D Apple Vision

A front-end project inspired by Apple Vision Pro, built using HTML, CSS, and JavaScript.

The website uses scroll-based animations, canvas image sequences, and video elements to create an immersive visual experience.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- GSAP
- GSAP ScrollTrigger
- Locomotive Scroll

## Features
- Scroll-controlled animations
- Canvas-based image sequence rendering
- Video-based visual sections
- Smooth scrolling experience

## How to Run
Open `index.html` in any modern browser.
